# Huduko

**Local semantic search for your Mac.** Find files and photos by meaning — not just filenames. Fully on-device. No cloud. No telemetry.

[**⬇ Download for macOS**](https://github.com/vijaykishen-real/huduko_release/releases/latest)

Requires macOS 13+ on Apple Silicon (M1 or later).

## Features
- Semantic search across PDFs, Word docs, Markdown, code, and more
- Find photos by description using CLIP (e.g., "sunset on a beach")
- Apple Photos library integration via PhotoKit
- Sub-250ms hybrid search (vector + BM25)
- 100% on-device — your files never leave your Mac
